=== ROUTER2 (public/NAT Externe) ===

hostname public

interface fastEthernet 0/0
ip address 10.0.0.1 255.255.255.248
no shutdown

interface fastEthernet 1/0
ip address 216.90.80.254 255.255.255.0
no shutdown



====configuration du routage avec RIP====
enable
configure terminal
router rip
version 2
network 216.90.80.0
network 10.0.0.0
no auto-summary
exit
end

// obliger d'utiliser le routage static car le modem SDL et le cloudPT sont des equipement de couche 2 qui envois uniquement des trame il ne laisse pas passer le routage RIP
configure terminal
ip route 216.90.90.0 255.255.255.0 216.90.80.252
ip route 216.90.100.0 255.255.255.0 216.90.80.252
end


// configuration du nat static pour le serveur public 

enable
configure terminal

ip nat inside source static 10.0.0.3 216.90.80.253

interface fastEthernet 0/0
ip nat inside
exit

interface fastEthernet 1/0
ip nat outside
exit


// nat dynamic PAT pour le reseau d'entreprise 

access-list 1 permit 172.16.0.0 0.0.255.255

ip nat inside source list 1 interface fastEthernet 1/0 overload

end

// Section 4.5 Protection de la DMZ

/*
La DMZ héberge Server2 (www.entreprise.com). Elle est accessible depuis internet MAIS on doit :
Laisser passer uniquement le HTTP (port 80) depuis internet vers le serveur web
Laisser passer le RIP pour que les routeurs maintiennent leurs tables de routage
Laisser passer ICMP en réponse pour l'administration réseau
Bloquer tout le reste depuis internet
*/

//configuration de l ACL 111 sur le routeur 
ACL 111 — En entrée sur Fa0/0 (côté DMZ)

enable
configure terminal

access-list 111 permit tcp any host 216.90.80.253 eq 80
access-list 111 permit tcp any 10.0.0.0 0.0.0.7 established
access-list 111 permit icmp any 10.0.0.0 0.0.0.7 echo-reply
access-list 111 permit icmp 172.16.0.0 0.0.255.255 10.0.0.0 0.0.0.7

//Activation sur l'interface Fa1/0

interface fastEthernet 1/0
ip access-group 111 in
exit
end


// conclusion 
"Le serveur web de l'entreprise devra aussi héberger un serveur FTP. Quelles sont les règles à ajouter ?"
Puisque le serveur FTP est sur Server2 (même machine que le serveur web), il faut autoriser le trafic FTP depuis internet vers 216.90.80.253 :

// on vas ajouter  juste les 2 regles la pour que l on puisse ajouter un server TFP
configure terminal
access-list 111 permit tcp any host 216.90.80.253 eq 21
access-list 111 permit tcp any host 216.90.80.253 eq 20
end


// reponse literraire a la question:
Pour héberger un serveur FTP sur le même serveur web, il faut ajouter deux règles à l'ACL 111
sur Router2 : autoriser le TCP port 21 (contrôle FTP) et le TCP port 20 (données FTP)
vers l'adresse publique 216.90.80.253. Ces règles permettent aux clients internet d'accéder 
au service FTP tout en maintenant la sécurité de la DMZ.
